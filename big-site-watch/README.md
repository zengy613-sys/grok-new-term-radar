# 大站内页更新监听

目的：监听 AI 大站的 sitemap，发现它们新上的内页（新工具页、新模型页、新玩法页），这些往往就是新关键词信号。
规则：只用公开 sitemap，不登录，不编造。

- sites.json：监听的站点列表（加站就往这里加一条）
- check.py：抓 sitemap，与 snapshots/ 里的上次快照比对，输出新增和删除的页面并更新快照；`--init` 只建基线
- snapshots/<域名>.txt：每个站上次的页面清单（默认去掉 /zh/、/ja/ 等多语言重复页）
- findings.md：每次的新增页面记录（日期、站点、新页面、推测的新词）
